# MATLAB – Geometric Modeling Exercises

Collection of **MATLAB** scripts created in 2024 while preparing the *Geometric Modeling & Virtual Prototyping* exam.  
First hands-on experience with MATLAB (≈64 commits). Exercises focus on B-splines and basic geometric transformations.

---

## Tech Stack
- **Programming language:** MATLAB
- **Libraries / helpers:** custom `bsl.*` utilities provided in the course (B-spline tools)
- **IDE:** MATLAB

---

## Main Features
- B-Spline curves: interpolation, knot vectors, basis (blending) functions, evaluation, export to `.txt`
- Geometric transforms: **scaling**, **translation**, **reflection** across a plane, **rotation** (Rodrigues' formula)
- Local ↔ global frames using **homogeneous coordinates**
- Small practice scripts for exam-style questions

*Project created for learning and portfolio purposes.*
